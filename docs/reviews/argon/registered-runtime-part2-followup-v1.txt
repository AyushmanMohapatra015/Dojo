## 1. Root-Cause Diagnosis: Frozen Stage B v1 `workspace_artifact_mismatch` vs. Proposal Changes

### Why the Five Supplied Tests Failed During Setup

1. **Unbypassed Host Preflight Verification Chain:**
* `prepare_bound_plan(directory, task_id, config_id, seed)` calls `execution_intent.build_intent(directory, task_id, config_id, seed)`.


* `build_intent` calls `registration_preflight.verify_workspace(directory)` both before and after reading the seven per-cell JSON artifacts (`draft`, `expected_plan`, `task_inputs`, `configurations`, `sampling_and_thinking`, `solver_image`, `scoring_image`).


* `verify_workspace(directory)` first verifies internal 12-file artifact integrity via `verify_artifacts(directory)` and then calls `expected = build_workspace_artifacts()`, requiring `read_file(Path(directory) / name) == data` for every file in `expected` (`PreflightError("workspace_artifact_mismatch")`).




2. **Distinguishing Existing Source Drift from Proposal Changes:**
* **Existing Workspace Source Drift vs. Frozen `data/development/stage-b-preflight-v1`:** `data/development/stage-b-preflight-v1` is a frozen checkpoint. `registration_preflight.SOURCE_FILES` pins 30 source files across `scaffold`, `collector`, `evaluator`, `source_policy`, and `baseline_policy`. Because workspace sources tracked in `SOURCE_FILES` evolved after `stage-b-preflight-v1` was written (even before applying any Part 2 diff), `build_workspace_artifacts()` computes live `_files(names)` digests that differ from the historical digests inside `data/development/stage-b-preflight-v1/{scaffold,collector,evaluator,source_policy,baseline_policy,draft}.json`, raising `PreflightError("workspace_artifact_mismatch")`.


* **Proposal Changes (`dojo/eval/docker_scoring_v2.py`):** `dojo/eval/docker_scoring_v2.py` is explicitly listed in `registration_preflight.SOURCE_FILES["evaluator"]`. Applying the guarded raw-scorer diff changes the SHA-256 of `dojo/eval/docker_scoring_v2.py` (from `593fbfd204f27b3d2825481246981e66c6f917dd96240c4d403d6e428249b363`), which updates `evaluator.json` and `draft.json` in any newly generated snapshot.




3. **Fixing Test Setup Without Modifying Frozen v1 Artifacts or Bypassing Host Preflight:**
* `data/development/stage-b-preflight-v1` must never be modified in place. In `stage_b_host`, we first assert `verify_artifacts(FROZEN_V1_DIRECTORY)` to verify that the frozen v1 bundle remains intact and internally consistent.


* Next, `stage_b_host` calls `registration_preflight.create_snapshot(snapshot_dir)` into a fresh pytest temporary directory (`tmp_path_factory.mktemp("stage_b_current") / "snapshot"`). `create_snapshot` runs the **real, unbypassed** `build_workspace_artifacts()` and `verify_workspace(snapshot_dir)` against the live workspace anchors (`input_guard_v2._trusted_bundle()`, `configs/models.yaml`, `split.lock.json`, and `SOURCE_FILES`).


* All calls to `prepare_bound_plan`, `build_intent`, `check_intent`, `IntentAttemptStore.claim_cell`, and `IntentAttemptStore.verify_cell` run unmocked against `snapshot_dir`. Only the read-only Git `cat-file --batch` reconstruction (`load_contract(TASK)` / `prepare_plan(TASK, settings)`) is cached from the module-scoped `prepare_bound_plan` result so the 22 tests do not spawn redundant Git subprocesses on every test function.

def make_receipt_envelope(
    contract: scoring_contract.ScoringContract,
    *,
    outcome: str = "passed",
) -> dict[str, Any]:
    """Build a valid canonical scoring envelope for contract."""
    f2p = list(contract.fail_to_pass)
    p2p = list(contract.pass_to_pass)
    skips = list(contract.stable_skips)
    total = len(f2p) + len(p2p) + len(skips)

    if outcome == "passed":
        report: dict[str, Any] = {
            "exit_code": 0,
            "collected": total,
            "passed": sorted(f2p + p2p),
            "failed": [],
            "skipped": sorted(skips),
            "errors": [],
        }
    elif outcome == "failed_baseline":
        report = {
            "exit_code": 1,
            "collected": total,
            "passed": sorted(p2p),
            "failed": sorted(f2p),
            "skipped": sorted(skips),
            "errors": [],
        }
    elif outcome == "collection_error":
        report = {
            "exit_code": 2,
            "collected": 0,
            "passed": [],
            "failed": [],
            "skipped": [],
            "errors": [contract.selectors[0]],
        }
    elif outcome == "stable_skip_drift":
        report = {
            "exit_code": 0,
            "collected": total,
            "passed": sorted(f2p + p2p + skips),
            "failed": [],
            "skipped": [],
            "errors": [],
        }
    else:
        raise ValueError(f"Unknown receipt outcome fixture: {outcome}")

    if contract.collector_protocol == "method-subtests-v2":
        report["collector_protocol"] = "method-subtests-v2"
        report["subtests"] = {}

    return {"phase": "pytest", "report": report, "install_exit_code": None}


def ledger_row(ledger: CreditLedger) -> tuple[int, int | None, str, int] | None:
    db = sqlite3.connect(ledger.path)
    try:
        res = db.execute("SELECT amount, usage, state FROM reservations").fetchone()
        pol = db.execute("SELECT blocked FROM policy WHERE id=1").fetchone()
        if res is None:
            return None
        return (res[0], res[1], res[2], pol[0])
    finally:
        db.close()


def observation_kinds(store: journal.ObservationStore, run_id: str) -> list[str]:
    db = sqlite3.connect(store.path)
    try:
        rows = db.execute(
            "SELECT kind FROM observation_events WHERE run_id=? ORDER BY ordinal", (run_id,)
        ).fetchall()
        return [r[0] for r in rows]
    finally:
        db.close()

## 4. No-Network Synthetic Integration Demo (`scripts/runtime_bridge_demo.py`, `UNEXECUTED`)

### Explicit Interface Audit for the No-Network Synthetic Demo (Correction #1 from `PRIMARY-REVIEW.md`)

Per **Required Correction #1** in `PRIMARY-REVIEW.md` and `PART2-REVIEW-ADDENDUM.md`:

* *"ObservationStore.claim_cell invokes prepare_bound_plan and build_intent; candidate_observation and scoring_observation invoke load_contract internally. A SyntheticCellAdapter alone cannot redirect these calls. Test monkeypatching does not establish a production path. Either propose narrow explicit synthetic interfaces with host-verified provenance, or keep synthetic rehearsal outside the registered observation store. Never forge Stage B records. ... Do not call `_execute` directly from the bridge or monkeypatch production modules."*


* Therefore, `scripts/runtime_bridge_demo.py` **never monkeypatches production modules** (`intent_attempts`, `observations`, `bound_plan`, or `execution_intent`). Instead, it provides two clean, unmonkeypatched no-network demonstration paths:


1. **Path 1 — Stage B Host-Preflight Rehearsal (`ObservationStore` v6 + `CreditLedger` + `FakeSandbox` + `FakeScoringAdapter`):** Creates a real temporary Stage B snapshot via `registration_preflight.create_snapshot(...)`, binds the real train task `click_6de212151893` through `ObservationStore` (schema v6) and `CreditLedger` with zero monkeypatching, and runs three cases (`fixed_solved`, `test_tampering_restored_unsolved`, and `syntax_error_baseline_attributed`).
2. **Path 2 — Pure Synthetic Fixture Rehearsal Outside `ObservationStore` (`BindingStore` v4 + `CreditLedger` + `contract_development.fixture` + `prepare_candidate_reference` + `assess_candidate` / `run_development_score_raw`):** Keeps `synthetic_method-subtests-v2` outside the registered Stage B `ObservationStore` (as directed by Correction #1 when `ObservationStore` is not edited), using `owned_adaptive.run_owned_rehearsal` (`BindingStore` v4 + `CreditLedger`) paired with `prepare_candidate_reference` and `assess_candidate` (offline default) or `docker_scoring_v2.run_development_score_raw` (`--with-local-docker`), with zero monkeypatching and zero forged Stage B records.

def _envelope(contract: scoring_contract.ScoringContract, kind: str) -> dict[str, Any]:
    f2p = list(contract.fail_to_pass)
    p2p = list(contract.pass_to_pass)
    skips = list(contract.stable_skips)
    total = len(f2p) + len(p2p) + len(skips)
    if kind == "passed":
        report: dict[str, Any] = {
            "exit_code": 0,
            "collected": total,
            "passed": sorted(f2p + p2p),
            "failed": [],
            "skipped": sorted(skips),
            "errors": [],
        }
    elif kind == "failed":
        report = {
            "exit_code": 1,
            "collected": total,
            "passed": sorted(p2p),
            "failed": sorted(f2p),
            "skipped": sorted(skips),
            "errors": [],
        }
    elif kind == "collection_error":
        report = {
            "exit_code": 2,
            "collected": 0,
            "passed": [],
            "failed": [],
            "skipped": [],
            "errors": [contract.selectors[0]],
        }
    else:
        raise ValueError(f"Unsupported demo receipt kind: {kind}")
    if contract.collector_protocol == "method-subtests-v2":
        report["collector_protocol"] = "method-subtests-v2"
        report["subtests"] = {}
    return {"phase": "pytest", "report": report, "install_exit_code": None}
