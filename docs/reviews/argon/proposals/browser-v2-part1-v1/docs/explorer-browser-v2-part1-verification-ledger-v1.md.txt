## 3. Deliberate Deviations & Known Limitations

- **Deliberate Deviations**: None. All exported function names, parameter signatures, error codes, resource limits (`LIMITS_V2`), and schema invariants match the assignment specification and the accepted Python validators (`explorer_export.py`, `sensitivity_diagnostics.py`, `evidence_bundle.py`).
- **What Static/Node Tests Cannot Establish**: Passing pure-JS Node tests does not establish React component rendering, Vite bundling, npm dependency resolution, CSP compliance, or browser accessibility. Those belong to Part 2 (`10j3`/`10j4`).

## 4. Part 2 Acceptance Risks to Track

1. **No `BigInt` in React State / JSON Serialization**: `DerivedV2` and `PageV2` intentionally keep all public DTOs as JSON-safe strings/booleans/numbers so React state or dev-tools serialization never encounters a raw `BigInt`. Part 2 components must consume `DerivedV2` / `PageV2` rather than holding `parseRationalV2` outputs in React state.
2. **Chart Coordinate Overflow**: Extremely large synthetic costs near `10^18` nano-USD (`$10^9` USD) remain finite in IEEE-754 `Number`, but Recharts axis tick formatting in Part 2 should use compact notation or fall back to the exact accessible table when domain ratios are extreme.
