Key Technical Decisions
Solver vs. Scoring Key Separation & Deliberate Inclusions/Exclusions:
SolverIdentity (dojo-solver-identity-v1) includes every parameter that can influence agent behavior or runtime termination: namespace (synthetic vs. live), task_id, source_archive_sha256, issue_sha256, input_protocol_sha256, model_id, api_base, sampling (temperature, top_p, seed), thinking (enabled, budget, force_nonempty_content), limits (max_steps, observation_chars, command_timeout_seconds, wall_seconds, token_ceiling, reply_tokens), context_tokens, scaffold_sha256, system_prompt_sha256, action_policy_sha256, tool_policy_sha256, docsearch (enabled, policy_sha256), bundle_sha256, visible_selectors_sha256, solver_image_id, and solver_harness_sha256.
Deliberate Exclusions from SolverIdentity: Provider alias (nano, super), Git commit SHA alone, evaluator metadata, and token pricing (input_usd_per_million, output_usd_per_million) are excluded. Alias is a local config shorthand; pricing changes affect accounting valuation (CostValuation), not the generated patch.
ScoringIdentity (dojo-scoring-identity-v1) binds solver_key + candidate_patch_sha256 (exact bytes digest) to evaluator provenance (evaluator_version, evaluator_source_sha256, contract_sha256, restoration_policy_sha256, collector_protocol, collector_sha256, scoring_image_id, scoring_harness_sha256, expectation_sha256, baseline_policy_sha256, and registration_id). Changing evaluator policy invalidates scoring_key while keeping completed solver artifacts reusable for offline rescoring.
Strict Type & Float Canonicalization (Zero Collision / No Silent Coercion):
Rejects bool where int or float is expected (type(v) is int), rejects NaN/Infinity, forbids missing or unknown dictionary keys on both input and stored JSON deserialization, and normalizes finite floats in SamplingSpec and LimitsSpec via Decimal(str(float(v))).normalize() formatted as a canonical fixed/scientific string (_canonical_number_str) so 1 and 1.0 serialize identically without float/Decimal/string collisions.
Archive and patch identities are SHA-256 digests of raw bytes—never line-ending normalized as text.
Retained History & Orthogonal State Dimensions:
Every claim creates a new row in solver_runs (attempt_id), preserving all failed, aborted, or interrupted attempts. At most one attempt per (namespace, solver_key) may be in an active (claimed, dispatched) or reusable (completed) terminal state unless explicitly superseded only from a pre-dispatch aborted_pre_dispatch state.
Outcomes are tracked across three separate dimensions:
execution_state: claimed, dispatched, completed, aborted_pre_dispatch, blocked_uncertain.
candidate_outcome (derived strictly from valid scoring, never from solver self-report): not_scored, solved, unsolved, undetermined.
evidence_validity: pending, valid, invalid_evidence, infrastructure_error.
SQLite Concurrency, Locking & Fixed Bounds:
Uses sqlite3.connect("...?mode=rw", uri=True, timeout=0) with BEGIN IMMEDIATE transactions, PRAGMA foreign_keys=ON, and PRAGMA synchronous=FULL (using default rollback journal mode DELETE for deterministic single-file semantics on local Windows filesystems without multi-file WAL checkpoint ambiguity).
Fixed bounds: MAX_PATCH_BYTES = 262_144 (256 KiB), MAX_TRAJECTORY_BYTES = 524_288 (512 KiB), MAX_JSON_BYTES = 65_536 (64 KiB), MAX_STRING_CHARS = 4_096, MAX_ID_CHARS = 256, MAX_REASON_CHARS = 512, MAX_MONEY_NANOS = 2**63 - 1.

Ordered Cache / CreditLedger Handshake & Crash-Point Matrix (ACTION_PLAN 5c / 6b–6d)
Because CreditLedger.reserve_run(amount_usd) generates its own uuid4().hex internally, allows at most one state != 'completed' reservation globally, and cannot atomically commit across two SQLite files, the coordinator must execute this exact 6-step handshake:
Step 1 (Pre-flight Ledger Check): Call ledger.status(now=now) and verify can_reserve is True and unfinished_runs == 0.
Step 2 (Cache Claim + Intent Marker): Call cache.claim_solver_run(...) followed by cache.begin_reservation_intent(attempt_id, owner_token, planned_usd=..., now=now).
Step 3 (Ledger Reservation): Call res_id = ledger.reserve_run(planned_usd, now=now).
Step 4 (Cache Bind Reservation + Dispatch Marker): Call cache.bind_reservation(attempt_id, owner_token, reservation_id=res_id, now=now) and cache.mark_dispatched(attempt_id, owner_token, now=now) immediately before the first network request.
Step 5 (Per-Request Check + Model Execution + Cache Artifact Commit): Before each request call ledger.check_run(res_id, now=now); on completion call cache.complete_solver_run(...) (or cache.fail_or_block_solver_run(...) on error/unknown usage).
Step 6 (Ledger Finalization): Call ledger.finish_run(res_id, actual_cost_usd_or_none) and then cache.mark_reservation_finalized(attempt_id, owner_token, ledger_state=..., now=now).

class CacheError(ValueError):
    """Base error for cache validation, schema, state, or storage failures."""


class CacheValidationError(CacheError):
    """Raised when identity, usage, money, or artifact fields fail validation."""


def ensure_utc_timestamp(value: datetime | str) -> str:
    """Validate an explicit-timezone datetime or ISO-8601 string and normalize to UTC ISO."""
    if isinstance(value, str):
        if not value or len(value) > 64:
            raise CacheValidationError("Invalid timestamp string length")
        try:
            parsed = datetime.fromisoformat(value)
        except ValueError as exc:
            raise CacheValidationError("Malformed ISO-8601 timestamp") from exc
    elif isinstance(value, datetime):
        parsed = value
    else:
        raise CacheValidationError("Timestamp must be a datetime or ISO-8601 string")
    if parsed.tzinfo is None or parsed.utcoffset() is None:
        raise CacheValidationError("Timestamp must include an explicit timezone")
    return parsed.astimezone(UTC).isoformat()


def parse_utc_timestamp(value: str) -> datetime:
    """Parse a stored UTC ISO-8601 string back into an aware datetime."""
    if not isinstance(value, str):
        raise CacheValidationError("Stored timestamp must be a string")
    try:
        parsed = datetime.fromisoformat(value)
    except ValueError as exc:
        raise CacheValidationError("Stored timestamp is malformed") from exc
    if parsed.tzinfo is None or parsed.utcoffset() is None:
        raise CacheValidationError("Stored timestamp lacks timezone")
    return parsed.astimezone(UTC)


def usd_to_nanos(
    value: object,
    *,
    allow_zero: bool = False,
    rounding: str = ROUND_CEILING,
) -> int:
    """Convert a finite USD value to integer 1e-9 USD units with strict overflow checks."""
    if isinstance(value, (bool, float)):
        raise CacheValidationError("Monetary USD amounts must be Decimal, int, or exact string")
    if not isinstance(value, (Decimal, int, str)):
        raise CacheValidationError("Unsupported monetary USD type")
    try:
        amount = Decimal(str(value))
        if not amount.is_finite() or amount < 0 or (amount == 0 and not allow_zero):
            raise CacheValidationError("Invalid monetary amount")
        nanos = int((amount * USD_NANO_SCALE).to_integral_value(rounding=rounding))
        if nanos > MAX_MONEY_NANOS or (nanos == 0 and not allow_zero):
            raise CacheValidationError("Monetary amount out of bounds")
        return nanos
    except (InvalidOperation, OverflowError, TypeError, ValueError) as exc:
        if isinstance(exc, CacheValidationError):
            raise
        raise CacheValidationError("Invalid monetary amount") from exc


def validate_nanos(value: object, *, allow_zero: bool = True, allow_none: bool = True) -> int | None:
    """Validate an already-scaled integer 1e-9 USD nano amount."""
    if value is None:
        if allow_none:
            return None
        raise CacheValidationError("Monetary nanos cannot be None")
    if type(value) is not int:
        raise CacheValidationError("Monetary nanos must be an exact int")
    if value < 0 or (value == 0 and not allow_zero) or value > MAX_MONEY_NANOS:
        raise CacheValidationError("Monetary nanos out of range")
    return value


def nanos_to_usd_str(nanos: int | None) -> str | None:
    """Format integer 1e-9 USD units as a canonical decimal string without float loss."""
    if nanos is None:
        return None
    validate_nanos(nanos, allow_zero=True, allow_none=False)
    text = format(Decimal(nanos) / USD_NANO_SCALE, "f")
    if "." in text:
        text = text.rstrip("0").rstrip(".")
    return text or "0"


def sha256_bytes(data: bytes) -> str:
    """Hash raw bytes without text encoding or newline normalization."""
    if type(data) is not bytes:
        raise CacheValidationError("Expected exact bytes for binary digest")
    return hashlib.sha256(data).hexdigest()


def _require_exact_keys(mapping: Any, required: set[str], context: str) -> dict[str, Any]:
    if type(mapping) is not dict:
        raise CacheValidationError(f"{context} must be a dict")
    actual = set(mapping.keys())
    if actual != required:
        missing = sorted(required - actual)
        extra = sorted(actual - required)
        raise CacheValidationError(
            f"{context} key mismatch (missing={missing}, extra={extra})"
        )
    return mapping


def _require_nonempty_str(value: Any, name: str, *, max_len: int = MAX_ID_CHARS) -> str:
    if type(value) is not str or not value or not value.strip():
        raise CacheValidationError(f"{name} must be a non-empty string")
    if len(value) > max_len or "\x00" in value:
        raise CacheValidationError(f"{name} exceeds bounds or contains NUL")
    try:
        value.encode("utf-8", errors="strict")
    except UnicodeEncodeError as exc:
        raise CacheValidationError(f"{name} contains invalid Unicode surrogates") from exc
    return value


def _require_hex64(value: Any, name: str) -> str:
    if type(value) is not str or not _HEX64_RE.match(value):
        raise CacheValidationError(f"{name} must be a 64-char lowercase hex SHA-256")
    return value


def _require_image_id(value: Any, name: str) -> str:
    if type(value) is not str or not _IMAGE_ID_RE.match(value):
        raise CacheValidationError(f"{name} must be 'sha256:<64 lowercase hex>'")
    return value


def _require_int(value: Any, name: str, *, minimum: int, maximum: int) -> int:
    if type(value) is not int or not (minimum <= value <= maximum):
        raise CacheValidationError(f"{name} must be an int in [{minimum}, {maximum}]")
    return value


def _require_bool(value: Any, name: str) -> bool:
    if type(value) is not bool:
        raise CacheValidationError(f"{name} must be a bool")
    return value


def _require_finite_number(
    value: Any,
    name: str,
    *,
    minimum: float,
    maximum: float,
    strictly_positive: bool = False,
) -> float:
    if type(value) not in (int, float) or not math.isfinite(value):
        raise CacheValidationError(f"{name} must be a finite int or float")
    fval = float(value)
    if fval < minimum or fval > maximum or (strictly_positive and fval <= 0.0):
        raise CacheValidationError(f"{name} is out of allowed bounds")
    return fval


def _canonical_number_str(value: float) -> str:
    """Convert a validated finite float to an unambiguous canonical decimal string."""
    if type(value) is not float or not math.isfinite(value):
        raise CacheValidationError("Expected validated finite float")
    dec = Decimal(str(value)).normalize()
    if dec == 0:
        return "0"
    text = format(dec, "f")
    if "." in text:
        text = text.rstrip("0").rstrip(".")
    return text


def _unique_json_pairs(pairs: list[tuple[str, Any]]) -> dict[str, Any]:
    result: dict[str, Any] = {}
    for key, val in pairs:
        if type(key) is not str or "\x00" in key:
            raise CacheValidationError("Invalid JSON key")
        if key in result:
            raise CacheValidationError(f"Duplicate JSON key: {key}")
        result[key] = val
    return result


def strict_json_loads(raw: str | bytes, *, max_bytes: int = MAX_JSON_BYTES) -> Any:
    """Parse JSON rejecting duplicate keys, NaN/Infinity, surrogates, and oversized payloads."""
    if isinstance(raw, str):
        try:
            encoded = raw.encode("utf-8", errors="strict")
        except UnicodeEncodeError as exc:
            raise CacheValidationError("Invalid UTF-8 in JSON text") from exc
    elif isinstance(raw, bytes):
        encoded = raw
    else:
        raise CacheValidationError("JSON input must be str or bytes")
    if len(encoded) > max_bytes:
        raise CacheValidationError("JSON payload exceeds size bound")
    try:
        text = encoded.decode("utf-8", errors="strict")
        return json.loads(
            text,
            object_pairs_hook=_unique_json_pairs,
            parse_constant=lambda c: (_ for _ in ()).throw(
                CacheValidationError(f"Forbidden JSON constant: {c}")
            ),
        )
    except (ValueError, TypeError, RecursionError) as exc:
        if isinstance(exc, CacheValidationError):
            raise
        raise CacheValidationError("Malformed JSON payload") from exc


def canonical_json_bytes(payload: Any, *, max_bytes: int = MAX_JSON_BYTES) -> bytes:
    """Serialize validated primitives into deterministic ASCII-safe canonical JSON bytes."""
    def _check(node: Any) -> None:
        if node is None or type(node) in (bool, int):
            return
        if type(node) is str:
            if "\x00" in node:
                raise CacheValidationError("NUL byte forbidden in canonical JSON string")
            try:
                node.encode("utf-8", errors="strict")
            except UnicodeEncodeError as exc:
                raise CacheValidationError("Surrogates forbidden in canonical JSON") from exc
            return
        if type(node) is list:
            for item in node:
                _check(item)
            return
        if type(node) is dict:
            for k, v in node.items():
                if type(k) is not str or "\x00" in k:
                    raise CacheValidationError("Canonical JSON dict keys must be non-NUL strings")
                _check(v)
            return
        # Raw floats/Decimals are forbidden in canonical identity trees; use _canonical_number_str
        raise CacheValidationError(
            f"Unsupported type in canonical JSON tree: {type(node).__name__}"
        )

    _check(payload)
    raw = json.dumps(
        payload,
        sort_keys=True,
        separators=(",", ":"),
        ensure_ascii=True,
        allow_nan=False,
    ).encode("ascii")
    if len(raw) > max_bytes:
        raise CacheValidationError("Canonical JSON exceeds maximum size bound")
    return raw


def domain_hash(domain: str, payload: dict[str, Any]) -> str:
    """Compute a domain-separated SHA-256 hex digest over canonical JSON."""
    envelope = {"domain": domain, "schema_version": SCHEMA_VERSION, "payload": payload}
    return hashlib.sha256(canonical_json_bytes(envelope)).hexdigest()


@dataclass(frozen=True)
class SamplingSpec:
    temperature: float
    top_p: float
    seed: int

    def __post_init__(self) -> None:
        temp = _require_finite_number(
            self.temperature, "sampling.temperature", minimum=0.0, maximum=2.0
        )
        top_p = _require_finite_number(
            self.top_p, "sampling.top_p", minimum=0.0, maximum=1.0, strictly_positive=True
        )
        _require_int(self.seed, "sampling.seed", minimum=0, maximum=2_147_483_647)
        object.__setattr__(self, "temperature", temp)
        object.__setattr__(self, "top_p", top_p)

    @classmethod
    def from_dict(cls, data: Any) -> SamplingSpec:
        d = _require_exact_keys(data, {"temperature", "top_p", "seed"}, "sampling")
        return cls(
            temperature=d["temperature"],
            top_p=d["top_p"],
            seed=d["seed"],
        )

    def to_canonical_dict(self) -> dict[str, Any]:
        return {
            "seed": self.seed,
            "temperature": _canonical_number_str(self.temperature),
            "top_p": _canonical_number_str(self.top_p),
        }

    @classmethod
    def from_canonical_dict(cls, data: Any) -> SamplingSpec:
        d = _require_exact_keys(data, {"temperature", "top_p", "seed"}, "sampling")
        if type(d["temperature"]) is not str or type(d["top_p"]) is not str:
            raise CacheValidationError("Stored canonical sampling numbers must be strings")
        try:
            temp = float(Decimal(d["temperature"]))
            top_p = float(Decimal(d["top_p"]))
        except (InvalidOperation, ValueError) as exc:
            raise CacheValidationError("Invalid stored sampling number") from exc
        return cls(temperature=temp, top_p=top_p, seed=d["seed"])

@dataclass(frozen=True)
class UsageEvidence:
    """Separates synthetic token estimates from actual provider token/cost evidence."""

    accounting_mode: str
    synthetic_prompt_tokens: int
    synthetic_completion_tokens: int
    provider_calls: int
    actual_prompt_tokens: int | None = None
    actual_completion_tokens: int | None = None
    actual_total_tokens: int | None = None
    actual_reasoning_tokens: int | None = None
    actual_cached_tokens: int | None = None
    explicit_zero_usage: bool = False

    def __post_init__(self) -> None:
        if (
            type(self.accounting_mode) is not str
            or self.accounting_mode not in VALID_ACCOUNTING_MODES
        ):
            raise CacheValidationError("Invalid accounting_mode")
        _require_int(
            self.synthetic_prompt_tokens,
            "synthetic_prompt_tokens",
            minimum=0,
            maximum=10_000_000,
        )
        _require_int(
            self.synthetic_completion_tokens,
            "synthetic_completion_tokens",
            minimum=0,
            maximum=10_000_000,
        )
        _require_int(self.provider_calls, "provider_calls", minimum=0, maximum=1_000)
        _require_bool(self.explicit_zero_usage, "explicit_zero_usage")

        actual_fields = (
            self.actual_prompt_tokens,
            self.actual_completion_tokens,
            self.actual_total_tokens,
            self.actual_reasoning_tokens,
            self.actual_cached_tokens,
        )
        if self.accounting_mode == "synthetic":
            if self.provider_calls != 0 or any(v is not None for v in actual_fields):
                raise CacheValidationError(
                    "Synthetic usage cannot record provider calls or actual provider tokens"
                )
        elif self.accounting_mode == "unknown":
            if any(v is not None for v in actual_fields):
                raise CacheValidationError("Unknown accounting_mode must leave actual tokens None")
        elif self.accounting_mode == "provider":
            if (
                self.actual_prompt_tokens is None
                or self.actual_completion_tokens is None
                or self.actual_total_tokens is None
            ):
                raise CacheValidationError(
                    "Provider accounting requires actual_prompt/completion/total_tokens"
                )
            p = _require_int(
                self.actual_prompt_tokens, "actual_prompt_tokens", minimum=0, maximum=100_000_000
            )
            c = _require_int(
                self.actual_completion_tokens,
                "actual_completion_tokens",
                minimum=0,
                maximum=100_000_000,
            )
            t = _require_int(
                self.actual_total_tokens, "actual_total_tokens", minimum=0, maximum=200_000_000
            )
            if t != p + c:
                raise CacheValidationError("actual_total_tokens must equal prompt + completion")
            if t == 0 and not self.explicit_zero_usage:
                raise CacheValidationError(
                    "Completed zero provider token usage requires explicit_zero_usage=True"
                )
            if t > 0 and self.provider_calls < 1:
                raise CacheValidationError("Positive provider tokens require provider_calls >= 1")
            if self.actual_reasoning_tokens is not None:
                r = _require_int(
                    self.actual_reasoning_tokens,
                    "actual_reasoning_tokens",
                    minimum=0,
                    maximum=100_000_000,
                )
                if r > c:
                    raise CacheValidationError("actual_reasoning_tokens exceeds completion_tokens")
            if self.actual_cached_tokens is not None:
                ca = _require_int(
                    self.actual_cached_tokens,
                    "actual_cached_tokens",
                    minimum=0,
                    maximum=100_000_000,
                )
                if ca > p:
                    raise CacheValidationError("actual_cached_tokens exceeds prompt_tokens")


@dataclass(frozen=True)
class CostValuation:
    """Pricing snapshot and integer 1e-9 USD cost valuation bound to actual provider tokens."""

    pricing_version: str
    input_usd_per_million: str
    output_usd_per_million: str
    cost_nanos: int
    explicit_zero_cost: bool = False

    def __post_init__(self) -> None:
        _require_nonempty_str(self.pricing_version, "pricing_version")
        _require_bool(self.explicit_zero_cost, "explicit_zero_cost")
        for label, price_str in (
            ("input_usd_per_million", self.input_usd_per_million),
            ("output_usd_per_million", self.output_usd_per_million),
        ):
            if type(price_str) is not str:
                raise CacheValidationError(f"{label} must be a decimal string")
            try:
                dec = Decimal(price_str)
            except InvalidOperation as exc:
                raise CacheValidationError(f"{label} is not a valid Decimal") from exc
            if not dec.is_finite() or dec <= 0:
                raise CacheValidationError(f"{label} must be finite and positive")
        validate_nanos(
            self.cost_nanos,
            allow_zero=self.explicit_zero_cost,
            allow_none=False,
        )

    @classmethod
    def from_token_usage(
        cls,
        *,
        pricing_version: str,
        input_usd_per_million: str | Decimal,
        output_usd_per_million: str | Decimal,
        prompt_tokens: int,
        completion_tokens: int,
        explicit_zero_cost: bool = False,
    ) -> CostValuation:
        """Compute exact integer 1e-9 USD cost from provider token counts and price snapshot."""
        _require_int(prompt_tokens, "prompt_tokens", minimum=0, maximum=100_000_000)
        _require_int(completion_tokens, "completion_tokens", minimum=0, maximum=100_000_000)
        in_str = str(input_usd_per_million)
        out_str = str(output_usd_per_million)
        try:
            in_dec = Decimal(in_str)
            out_dec = Decimal(out_str)
        except InvalidOperation as exc:
            raise CacheValidationError("Invalid token price") from exc
        if not in_dec.is_finite() or in_dec <= 0 or not out_dec.is_finite() or out_dec <= 0:
            raise CacheValidationError("Token prices must be finite and positive")
        usd_amount = (
            Decimal(prompt_tokens) * in_dec + Decimal(completion_tokens) * out_dec
        ) / Decimal(1_000_000)
        nanos = usd_to_nanos(
            usd_amount,
            allow_zero=explicit_zero_cost,
            rounding=ROUND_CEILING,
        )
        return cls(
            pricing_version=pricing_version,
            input_usd_per_million=in_str,
            output_usd_per_million=out_str,
            cost_nanos=nanos,
            explicit_zero_cost=explicit_zero_cost,
        )

class SolverArtifact:
    """Bounded solver output artifact stored on completion."""

    stop_reason: str
    turns: int
    commands: int
    invalid_turns: int
    command_timeouts: int
    wall_elapsed_seconds: float
    patch_bytes: bytes
    trajectory_events: tuple[dict[str, Any], ...]
    has_patch: bool
    visible_tests_pass: bool | None
    hit_step_cap: bool
    no_command_rate: float
    agent_self_reports_done: bool
    execution_backend: str

    def __post_init__(self) -> None:
        _require_nonempty_str(self.stop_reason, "stop_reason", max_len=MAX_REASON_CHARS)
        _require_int(self.turns, "turns", minimum=0, maximum=40)
        _require_int(self.commands, "commands", minimum=0, maximum=40)
        _require_int(self.invalid_turns, "invalid_turns", minimum=0, maximum=40)
        _require_int(self.command_timeouts, "command_timeouts", minimum=0, maximum=40)
        elapsed = _require_finite_number(
            self.wall_elapsed_seconds,
            "wall_elapsed_seconds",
            minimum=0.0,
            maximum=3600.0,
        )
        object.__setattr__(self, "wall_elapsed_seconds", elapsed)
        if type(self.patch_bytes) is not bytes:
            raise CacheValidationError("patch_bytes must be exact bytes")
        if len(self.patch_bytes) > MAX_PATCH_BYTES:
            raise CacheValidationError("patch_bytes exceeds MAX_PATCH_BYTES")
        if b"\x00" in self.patch_bytes:
            raise CacheValidationError("Binary NUL byte forbidden in patch_bytes")
        if type(self.trajectory_events) is not tuple:
            raise CacheValidationError("trajectory_events must be a tuple of dicts")
        if len(self.trajectory_events) > MAX_TRAJECTORY_EVENTS:
            raise CacheValidationError("trajectory_events exceeds MAX_TRAJECTORY_EVENTS")
        # Validate trajectory serializes within MAX_TRAJECTORY_BYTES
        canonical_json_bytes(
            list(self.trajectory_events), max_bytes=MAX_TRAJECTORY_BYTES
        )
        _require_bool(self.has_patch, "has_patch")
        if self.visible_tests_pass is not None:
            _require_bool(self.visible_tests_pass, "visible_tests_pass")
        _require_bool(self.hit_step_cap, "hit_step_cap")
        rate = _require_finite_number(
            self.no_command_rate, "no_command_rate", minimum=0.0, maximum=1.0
        )
        object.__setattr__(self, "no_command_rate", rate)
        _require_bool(self.agent_self_reports_done, "agent_self_reports_done")
        _require_nonempty_str(self.execution_backend, "execution_backend")
        if self.has_patch != bool(self.patch_bytes.strip()):
            raise CacheValidationError("has_patch contradicts patch_bytes content")

    @property
    def patch_sha256(self) -> str:
        return sha256_bytes(self.patch_bytes)

def _now_iso(now: datetime | None) -> str:
    return ensure_utc_timestamp(now if now is not None else datetime.now(UTC))


class RunCache:
    """Crash-safe SQLite store for solver runs, evaluator scores, and ledger handshakes."""

    def __init__(self, path: Path = DEFAULT_CACHE_DB) -> None:
        if not isinstance(path, Path):
            raise CacheValidationError("Database path must be a pathlib.Path")
        if "\x00" in str(path):
            raise CacheValidationError("Invalid NUL character in database path")
        self.path = path

    def initialize(self, *, now: datetime | None = None) -> None:
        """Create a new cache database once; never overwrite an existing file."""
        created_iso = _now_iso(now)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        # Exclusive creation ('xb') guarantees we never truncate or overwrite existing DB
        with self.path.open("xb"):
            pass
        db = None
        try:
            uri = self.path.resolve().as_uri() + "?mode=rw"
            db = sqlite3.connect(uri, uri=True, timeout=0, isolation_level=None)
            db.row_factory = sqlite3.Row
            db.execute("PRAGMA foreign_keys = ON")
            db.execute("PRAGMA journal_mode = DELETE")
            db.execute("PRAGMA synchronous = FULL")
            db.execute("BEGIN IMMEDIATE")
            db.executescript(_DDL)
            db.execute(
                "INSERT INTO cache_meta (id, schema_version, application, created_at) "
                "VALUES (1, ?, 'dojo-run-cache', ?)",
                (SCHEMA_VERSION, created_iso),
            )
            db.commit()
        except sqlite3.Error as exc:
            if db is not None:
                try:
                    db.rollback()
                except sqlite3.Error:
                    pass
            raise CacheError("Failed to initialize cache database") from exc
        finally:
            if db is not None:
                db.close()

    @contextmanager
    def _transaction(self):
        """Open a short immediate transaction on an existing, schema-verified DB."""
        if not self.path.exists():
            raise CacheMissingError("Cache database does not exist; initialize explicitly")
        db = None
        try:
            uri = self.path.resolve().as_uri() + "?mode=rw"
            db = sqlite3.connect(uri, uri=True, timeout=0, isolation_level=None)
            db.row_factory = sqlite3.Row
            db.execute("PRAGMA foreign_keys = ON")
            db.execute("PRAGMA synchronous = FULL")
            db.execute("BEGIN IMMEDIATE")
            self._verify_schema(db)
            yield db
            db.commit()
        except sqlite3.OperationalError as exc:
            if db is not None:
                try:
                    db.rollback()
                except sqlite3.Error:
                    pass
            msg = str(exc).lower()
            if "locked" in msg or "busy" in msg:
                raise CacheBusyError("Cache database is busy or locked; stop") from None
            if "unable to open" in msg:
                raise CacheMissingError("Cache database cannot be opened") from None
            raise CacheSchemaError("Cache database operational/schema failure") from None
        except sqlite3.DatabaseError as exc:
            if db is not None:
                try:
                    db.rollback()
                except sqlite3.Error:
                    pass
            raise CacheSchemaError("Cache database is corrupt or invalid") from exc
        except BaseException:
            if db is not None:
                try:
                    db.rollback()
                except sqlite3.Error:
                    pass
            raise
        finally:
            if db is not None:
                db.close()

    def _verify_schema(self, db: sqlite3.Connection) -> None:
        tables = {
            row["name"]
            for row in db.execute(
                "SELECT name FROM sqlite_master WHERE type='table'"
            ).fetchall()
        }
        if tables != _EXPECTED_TABLES:
            raise CacheSchemaError("Unrecognized database table set")
        meta = db.execute("SELECT * FROM cache_meta WHERE id = 1").fetchone()
        if (
            meta is None
            or type(meta["schema_version"]) is not int
            or meta["schema_version"] != SCHEMA_VERSION
            or meta["application"] != "dojo-run-cache"
        ):
            raise CacheSchemaError("Unsupported or mismatched cache schema version")

    def _verify_solver_row_integrity(self, row: sqlite3.Row) -> None:
        """Verify stored solver run invariants so corrupted rows fail closed."""
        if row["namespace"] not in VALID_NAMESPACES:
            raise CacheCorruptionError("Invalid stored namespace")
        if row["execution_state"] not in VALID_EXECUTION_STATES:
            raise CacheCorruptionError("Invalid stored execution_state")
        if row["candidate_outcome"] not in VALID_CANDIDATE_OUTCOMES:
            raise CacheCorruptionError("Invalid stored candidate_outcome")
        if row["evidence_validity"] not in VALID_EVIDENCE_VALIDITIES:
            raise CacheCorruptionError("Invalid stored evidence_validity")
        if row["reservation_state"] not in VALID_RESERVATION_STATES:
            raise CacheCorruptionError("Invalid stored reservation_state")
        if row["execution_state"] == "completed":
            if (
                row["stop_reason"] is None
                or row["turns"] is None
                or row["commands"] is None
                or row["patch_bytes"] is None
                or row["patch_sha256"] is None
                or row["trajectory_json"] is None
                or row["accounting_mode"] is None
            ):
                raise CacheCorruptionError("Completed solver run is missing required artifacts")
            if type(row["patch_bytes"]) is not bytes or len(row["patch_bytes"]) > MAX_PATCH_BYTES:
                raise CacheCorruptionError("Corrupt stored patch_bytes")
            if sha256_bytes(row["patch_bytes"]) != row["patch_sha256"]:
                raise CacheCorruptionError("Stored patch_bytes does not match patch_sha256")
            traj = strict_json_loads(
                row["trajectory_json"], max_bytes=MAX_TRAJECTORY_BYTES
            )
            if type(traj) is not list:
                raise CacheCorruptionError("Stored trajectory_json must be a list")
            if row["namespace"] == "synthetic" and row["accounting_mode"] != "synthetic":
                raise CacheCorruptionError("Synthetic namespace run has non-synthetic accounting")
            if row["namespace"] == "live" and row["accounting_mode"] != "provider":
                raise CacheCorruptionError("Completed live run must have provider accounting")

    def register_solver_identity(
        self,
        identity: SolverIdentity,
        *,
        now: datetime | None = None,
    ) -> str:
        """Validate and idempotently store a SolverIdentity, returning solver_key."""
        if type(identity) is not SolverIdentity:
            raise CacheValidationError("Expected a SolverIdentity instance")
        now_iso = _now_iso(now)
        key = identity.solver_key()
        canon_json = canonical_json_bytes(identity.to_canonical_dict()).decode("ascii")
        with self._transaction() as db:
            existing = db.execute(
                "SELECT * FROM solver_identities WHERE solver_key = ?", (key,)
            ).fetchone()
            if existing is not None:
                stored_id = SolverIdentity.from_canonical_json(existing["identity_json"])
                if (
                    stored_id.solver_key() != key
                    or existing["identity_json"] != canon_json
                    or existing["namespace"] != identity.namespace
                ):
                    raise CacheCorruptionError("Stored solver identity collision or corruption")
                return key
            db.execute(
                "INSERT INTO solver_identities "
                "(solver_key, namespace, task_id, model_id, api_base, identity_json, created_at) "
                "VALUES (?, ?, ?, ?, ?, ?, ?)",
                (
                    key,
                    identity.namespace,
                    identity.task_id,
                    identity.model_id,
                    identity.api_base,
                    canon_json,
                    now_iso,
                ),
            )
        return key

    def check_live_handshake_ready(self, ledger_status: dict[str, Any] | None = None) -> None:
        """Verify neither the cache nor CreditLedger has an unfinished/orphan live run."""
        with self._transaction() as db:
            unfinished = db.execute(
                "SELECT attempt_id, execution_state, reservation_state, reservation_id "
                "FROM solver_runs "
                "WHERE namespace = 'live' AND ("
                "  execution_state IN ('claimed', 'dispatched', 'blocked_uncertain') "
                "  OR reservation_state IN ('intent_pending', 'reserved', 'finalized_uncertain')"
                ")"
            ).fetchone()
            if unfinished is not None:
                raise CacheBlockedError(
                    f"Live runs are blocked by unfinished or uncertain cache run "
                    f"(attempt_id={unfinished['attempt_id']}, "
                    f"execution_state={unfinished['execution_state']}, "
                    f"reservation_state={unfinished['reservation_state']})"
                )
            if ledger_status is not None:
                if type(ledger_status) is not dict:
                    raise CacheValidationError("ledger_status must be a dict")
                if (
                    ledger_status.get("unfinished_runs", 1) != 0
                    or ledger_status.get("can_reserve") is not True
                ):
                    raise CacheBlockedError(
                        "Live runs are blocked by an unfinished or unlinked CreditLedger reservation"
                    )

    def claim_solver_run(
        self,
        identity: SolverIdentity,
        *,
        lease_seconds: int = DEFAULT_LEASE_SECONDS,
        now: datetime | None = None,
        ledger_status: dict[str, Any] | None = None,
    ) -> ClaimOutcome:
        """Atomically claim a solver run or return deterministic existing status."""
        if type(identity) is not SolverIdentity:
            raise CacheValidationError("Expected a SolverIdentity instance")
        if type(lease_seconds) is not int or not (1 <= lease_seconds <= 86_400):
            raise CacheValidationError("lease_seconds must be an int in [1, 86400]")
        now_dt = parse_utc_timestamp(_now_iso(now))
        now_iso = now_dt.isoformat()
        expires_iso = (now_dt + timedelta(seconds=lease_seconds)).isoformat()
        key = identity.solver_key()
        canon_json = canonical_json_bytes(identity.to_canonical_dict()).decode("ascii")

        with self._transaction() as db:
            existing_id = db.execute(
                "SELECT * FROM solver_identities WHERE solver_key = ?", (key,)
            ).fetchone()
            if existing_id is None:
                db.execute(
                    "INSERT INTO solver_identities "
                    "(solver_key, namespace, task_id, model_id, api_base, identity_json, created_at) "
                    "VALUES (?, ?, ?, ?, ?, ?, ?)",
                    (
                        key,
                        identity.namespace,
                        identity.task_id,
                        identity.model_id,
                        identity.api_base,
                        canon_json,
                        now_iso,
                    ),
                )
            else:
                stored_id = SolverIdentity.from_canonical_json(existing_id["identity_json"])
                if stored_id.solver_key() != key or existing_id["identity_json"] != canon_json:
                    raise CacheCorruptionError("Stored solver identity corruption detected")

            row = db.execute(
                "SELECT * FROM solver_runs "
                "WHERE namespace = ? AND solver_key = ? "
                "AND execution_state IN ('claimed', 'dispatched', 'completed', 'blocked_uncertain')",
                (identity.namespace, key),
            ).fetchone()

            if row is not None:
                self._verify_solver_row_integrity(row)
                state = row["execution_state"]
                if state == "completed":
                    status = "reused_completed"
                elif state == "blocked_uncertain":
                    status = "blocked_uncertain"
                else:
                    status = "already_claimed"
                return ClaimOutcome(
                    status=status,
                    acquired=False,
                    solver_key=key,
                    attempt_id=row["attempt_id"],
                    owner_token=None,
                    execution_state=state,
                    dispatched=bool(row["dispatched"]),
                )

            if identity.namespace == "live":
                unfinished = db.execute(
                    "SELECT attempt_id FROM solver_runs "
                    "WHERE namespace = 'live' AND ("
                    "  execution_state IN ('claimed', 'dispatched', 'blocked_uncertain') "
                    "  OR reservation_state IN ('intent_pending', 'reserved', 'finalized_uncertain')"
                    ")"
                ).fetchone()
                if unfinished is not None:
                    raise CacheBlockedError(
                        "Cannot claim a new live run while an earlier live run is unfinished or uncertain"
                    )
                if ledger_status is not None:
                    if (
                        type(ledger_status) is not dict
                        or ledger_status.get("unfinished_runs", 1) != 0
                        or ledger_status.get("can_reserve") is not True
                    ):
                        raise CacheBlockedError(
                            "CreditLedger has unfinished or blocked reservation; refusing live claim"
                        )

            attempt_id = uuid4().hex
            owner_token = uuid4().hex
            db.execute(
                "INSERT INTO solver_runs ("
                "  attempt_id, solver_key, namespace, task_id, owner_token, "
                "  claimed_at, lease_expires_at, updated_at, execution_state, "
                "  candidate_outcome, evidence_validity, dispatched, reservation_state"
                ") VALUES (?, ?, ?, ?, ?, ?, ?, ?, 'claimed', 'not_scored', 'pending', 0, 'none')",
                (
                    attempt_id,
                    key,
                    identity.namespace,
                    identity.task_id,
                    owner_token,
                    now_iso,
                    expires_iso,
                    now_iso,
                ),
            )
            return ClaimOutcome(
                status="acquired",
                acquired=True,
                solver_key=key,
                attempt_id=attempt_id,
                owner_token=owner_token,
                execution_state="claimed",
                dispatched=False,
            )

    def _require_owned_solver_run(
        self,
        db: sqlite3.Connection,
        attempt_id: str,
        owner_token: str,
        now_dt: datetime,
        *,
        check_lease: bool = True,
    ) -> sqlite3.Row:
        _require_nonempty_str(attempt_id, "attempt_id")
        _require_nonempty_str(owner_token, "owner_token")
        row = db.execute(
            "SELECT * FROM solver_runs WHERE attempt_id = ?", (attempt_id,)
        ).fetchone()
        if row is None:
            raise CacheOwnershipError("Unknown solver attempt_id")
        self._verify_solver_row_integrity(row)
        if row["owner_token"] != owner_token:
            raise CacheOwnershipError("Invalid or stale owner_token for solver run")
        if check_lease:
            lease_exp = parse_utc_timestamp(row["lease_expires_at"])
            if now_dt >= lease_exp:
                raise CacheOwnershipError("Solver run lease has expired; owner is fenced")
        return row

    def begin_reservation_intent(
        self,
        attempt_id: str,
        owner_token: str,
        *,
        planned_usd: object,
        now: datetime | None = None,
    ) -> int:
        """Record durable pre-reserve intent before calling CreditLedger.reserve_run."""
        now_dt = parse_utc_timestamp(_now_iso(now))
        nanos = usd_to_nanos(planned_usd, allow_zero=False)
        with self._transaction() as db:
            row = self._require_owned_solver_run(db, attempt_id, owner_token, now_dt)
            if row["namespace"] != "live":
                raise CacheStateError("Monetary reservations apply only to 'live' namespace")
            if (
                row["execution_state"] != "claimed"
                or row["dispatched"] != 0
                or row["reservation_state"] != "none"
            ):
                raise CacheStateError("Run is not eligible for begin_reservation_intent")
            cur = db.execute(
                "UPDATE solver_runs "
                "SET reservation_state = 'intent_pending', "
                "    planned_reservation_nanos = ?, "
                "    updated_at = ? "
                "WHERE attempt_id = ? AND owner_token = ? "
                "  AND execution_state = 'claimed' AND dispatched = 0 AND reservation_state = 'none'",
                (nanos, now_dt.isoformat(), attempt_id, owner_token),
            )
            if cur.rowcount != 1:
                raise CacheStateError("Failed to record reservation intent")
        return nanos

    def bind_reservation(
        self,
        attempt_id: str,
        owner_token: str,
        *,
        reservation_id: str,
        now: datetime | None = None,
    ) -> None:
        """Durably associate CreditLedger's returned reservation_id with the claimed run."""
        _require_nonempty_str(reservation_id, "reservation_id")
        now_dt = parse_utc_timestamp(_now_iso(now))
        with self._transaction() as db:
            row = self._require_owned_solver_run(db, attempt_id, owner_token, now_dt)
            if (
                row["namespace"] != "live"
                or row["execution_state"] != "claimed"
                or row["dispatched"] != 0
                or row["reservation_state"] != "intent_pending"
            ):
                raise CacheStateError("Run must be in 'intent_pending' before bind_reservation")
            cur = db.execute(
                "UPDATE solver_runs "
                "SET reservation_state = 'reserved', "
                "    reservation_id = ?, "
                "    updated_at = ? "
                "WHERE attempt_id = ? AND owner_token = ? "
                "  AND execution_state = 'claimed' AND reservation_state = 'intent_pending'",
                (reservation_id, now_dt.isoformat(), attempt_id, owner_token),
            )
            if cur.rowcount != 1:
                raise CacheStateError("Failed to bind reservation_id")

    def abort_before_dispatch(
        self,
        attempt_id: str,
        owner_token: str,
        *,
        reason: str,
        now: datetime | None = None,
    ) -> None:
        """Safely release a claim ONLY when neither reservation nor dispatch has occurred."""
        _require_nonempty_str(reason, "reason", max_len=MAX_REASON_CHARS)
        now_dt = parse_utc_timestamp(_now_iso(now))
        with self._transaction() as db:
            row = self._require_owned_solver_run(
                db, attempt_id, owner_token, now_dt, check_lease=False
            )
            if (
                row["execution_state"] != "claimed"
                or row["dispatched"] != 0
                or row["reservation_state"] != "none"
            ):
                raise CacheStateError(
                    "Cannot abort_before_dispatch after reservation intent or dispatch"
                )
            cur = db.execute(
                "UPDATE solver_runs "
                "SET execution_state = 'aborted_pre_dispatch', "
                "    evidence_validity = 'infrastructure_error', "
                "    failure_reason = ?, "
                "    updated_at = ? "
                "WHERE attempt_id = ? AND owner_token = ? "
                "  AND execution_state = 'claimed' AND dispatched = 0 AND reservation_state = 'none'",
                (reason, now_dt.isoformat(), attempt_id, owner_token),
            )
            if cur.rowcount != 1:
                raise CacheStateError("Failed to abort pre-dispatch run")

    def mark_dispatched(
        self,
        attempt_id: str,
        owner_token: str,
        *,
        now: datetime | None = None,
    ) -> None:
        """Record that a request is about to be sent; permanently forbids silent rerun."""
        now_dt = parse_utc_timestamp(_now_iso(now))
        with self._transaction() as db:
            row = self._require_owned_solver_run(db, attempt_id, owner_token, now_dt)
            if row["execution_state"] != "claimed" or row["dispatched"] != 0:
                raise CacheStateError("Run must be in 'claimed' state with dispatched=0")
            if row["namespace"] == "live" and (
                row["reservation_state"] != "reserved" or not row["reservation_id"]
            ):
                raise CacheStateError(
                    "Live run cannot mark_dispatched without a bound CreditLedger reservation"
                )
            cur = db.execute(
                "UPDATE solver_runs "
                "SET execution_state = 'dispatched', "
                "    dispatched = 1, "
                "    dispatched_at = ?, "
                "    updated_at = ? "
                "WHERE attempt_id = ? AND owner_token = ? "
                "  AND execution_state = 'claimed' AND dispatched = 0",
                (now_dt.isoformat(), now_dt.isoformat(), attempt_id, owner_token),
            )
            if cur.rowcount != 1:
                raise CacheStateError("Failed to mark solver run as dispatched")

    def complete_solver_run(
        self,
        attempt_id: str,
        owner_token: str,
        *,
        artifact: SolverArtifact,
        usage: UsageEvidence,
        valuation: CostValuation | None = None,
        now: datetime | None = None,
    ) -> None:
        """Atomically persist validated solver artifacts and usage before marking reusable."""
        if type(artifact) is not SolverArtifact:
            raise CacheValidationError("Expected a SolverArtifact instance")
        if type(usage) is not UsageEvidence:
            raise CacheValidationError("Expected a UsageEvidence instance")
        if valuation is not None and type(valuation) is not CostValuation:
            raise CacheValidationError("valuation must be a CostValuation or None")
        now_dt = parse_utc_timestamp(_now_iso(now))
        now_iso = now_dt.isoformat()

        with self._transaction() as db:
            row = self._require_owned_solver_run(db, attempt_id, owner_token, now_dt)
            namespace = row["namespace"]
            if namespace == "synthetic":
                if row["execution_state"] not in {"claimed", "dispatched"}:
                    raise CacheStateError("Synthetic run must be claimed or dispatched")
                if usage.accounting_mode != "synthetic":
                    raise CacheValidationError(
                        "Synthetic namespace requires synthetic accounting_mode"
                    )
                if valuation is not None:
                    raise CacheValidationError(
                        "Synthetic runs must not record monetary provider CostValuation"
                    )
            else:
                if row["execution_state"] != "dispatched" or row["dispatched"] != 1:
                    raise CacheStateError("Live run must be marked dispatched before completion")
                if row["reservation_state"] != "reserved" or not row["reservation_id"]:
                    raise CacheStateError("Live run lacks active reservation binding")
                if usage.accounting_mode != "provider":
                    raise CacheValidationError(
                        "Completed live run requires 'provider' accounting_mode; "
                        "use fail_or_block_solver_run for unknown usage"
                    )
                if valuation is None:
                    raise CacheValidationError("Completed live run requires CostValuation")
                if (
                    row["planned_reservation_nanos"] is not None
                    and valuation.cost_nanos > row["planned_reservation_nanos"]
                ):
                    raise CacheStateError(
                        "Actual cost exceeds planned reservation; use fail_or_block_solver_run"
                    )

            traj_json = canonical_json_bytes(
                list(artifact.trajectory_events), max_bytes=MAX_TRAJECTORY_BYTES
            ).decode("ascii")
            patch_digest = artifact.patch_sha256

            cur = db.execute(
                "UPDATE solver_runs SET "
                "  execution_state = 'completed', "
                "  candidate_outcome = 'not_scored', "
                "  evidence_validity = 'valid', "
                "  updated_at = ?, "
                "  stop_reason = ?, "
                "  turns = ?, "
                "  commands = ?, "
                "  invalid_turns = ?, "
                "  command_timeouts = ?, "
                "  wall_elapsed_seconds = ?, "
                "  patch_bytes = ?, "
                "  patch_sha256 = ?, "
                "  trajectory_json = ?, "
                "  has_patch = ?, "
                "  visible_tests_pass = ?, "
                "  hit_step_cap = ?, "
                "  no_command_rate = ?, "
                "  agent_self_reports_done = ?, "
                "  execution_backend = ?, "
                "  accounting_mode = ?, "
                "  provider_calls = ?, "
                "  synthetic_prompt_tokens = ?, "
                "  synthetic_completion_tokens = ?, "
                "  actual_prompt_tokens = ?, "
                "  actual_completion_tokens = ?, "
                "  actual_total_tokens = ?, "
                "  actual_reasoning_tokens = ?, "
                "  actual_cached_tokens = ?, "
                "  explicit_zero_usage = ?, "
                "  original_cost_nanos = ?, "
                "  original_pricing_version = ?, "
                "  original_input_price_usd_per_m = ?, "
                "  original_output_price_usd_per_m = ? "
                "WHERE attempt_id = ? AND owner_token = ? "
                "  AND execution_state IN ('claimed', 'dispatched')",
                (
                    now_iso,
                    artifact.stop_reason,
                    artifact.turns,
                    artifact.commands,
                    artifact.invalid_turns,
                    artifact.command_timeouts,
                    str(artifact.wall_elapsed_seconds),
                    artifact.patch_bytes,
                    patch_digest,
                    traj_json,
                    int(artifact.has_patch),
                    None
                    if artifact.visible_tests_pass is None
                    else int(artifact.visible_tests_pass),
                    int(artifact.hit_step_cap),
                    str(artifact.no_command_rate),
                    int(artifact.agent_self_reports_done),
                    artifact.execution_backend,
                    usage.accounting_mode,
                    usage.provider_calls,
                    usage.synthetic_prompt_tokens,
                    usage.synthetic_completion_tokens,
                    usage.actual_prompt_tokens,
                    usage.actual_completion_tokens,
                    usage.actual_total_tokens,
                    usage.actual_reasoning_tokens,
                    usage.actual_cached_tokens,
                    int(usage.explicit_zero_usage),
                    None if valuation is None else valuation.cost_nanos,
                    None if valuation is None else valuation.pricing_version,
                    None if valuation is None else valuation.input_usd_per_million,
                    None if valuation is None else valuation.output_usd_per_million,
                    attempt_id,
                    owner_token,
                ),
            )
            if cur.rowcount != 1:
                raise CacheStateError("Failed to complete solver run")

            if valuation is not None:
                db.execute(
                    "INSERT INTO cost_valuations ("
                    "  valuation_id, attempt_id, is_original, pricing_version, "
                    "  input_price_usd_per_m, output_price_usd_per_m, cost_nanos, "
                    "  explicit_zero_cost, recorded_at"
                    ") VALUES (?, ?, 1, ?, ?, ?, ?, ?, ?)",
                    (
                        uuid4().hex,
                        attempt_id,
                        valuation.pricing_version,
                        valuation.input_usd_per_million,
                        valuation.output_usd_per_million,
                        valuation.cost_nanos,
                        int(valuation.explicit_zero_cost),
                        now_iso,
                    ),
                )

    def fail_or_block_solver_run(
        self,
        attempt_id: str,
        owner_token: str,
        *,
        reason: str,
        usage: UsageEvidence | None = None,
        now: datetime | None = None,
    ) -> None:
        """Transition an interrupted, unknown-usage, or failed run to blocked_uncertain."""
        _require_nonempty_str(reason, "reason", max_len=MAX_REASON_CHARS)
        if usage is not None and type(usage) is not UsageEvidence:
            raise CacheValidationError("usage must be UsageEvidence or None")
        now_dt = parse_utc_timestamp(_now_iso(now))
        with self._transaction() as db:
            row = self._require_owned_solver_run(
                db, attempt_id, owner_token, now_dt, check_lease=False
            )
            if row["execution_state"] not in {"claimed", "dispatched"}:
                raise CacheStateError("Only claimed or dispatched runs can be failed/blocked")
            acc_mode = "unknown" if usage is None else usage.accounting_mode
            cur = db.execute(
                "UPDATE solver_runs SET "
                "  execution_state = 'blocked_uncertain', "
                "  candidate_outcome = 'undetermined', "
                "  evidence_validity = 'infrastructure_error', "
                "  accounting_mode = ?, "
                "  provider_calls = ?, "
                "  synthetic_prompt_tokens = ?, "
                "  synthetic_completion_tokens = ?, "
                "  actual_prompt_tokens = ?, "
                "  actual_completion_tokens = ?, "
                "  actual_total_tokens = ?, "
                "  actual_reasoning_tokens = ?, "
                "  actual_cached_tokens = ?, "
                "  failure_reason = ?, "
                "  updated_at = ? "
                "WHERE attempt_id = ? AND owner_token = ? "
                "  AND execution_state IN ('claimed', 'dispatched')",
                (
                    acc_mode,
                    None if usage is None else usage.provider_calls,
                    None if usage is None else usage.synthetic_prompt_tokens,
                    None if usage is None else usage.synthetic_completion_tokens,
                    None if usage is None else usage.actual_prompt_tokens,
                    None if usage is None else usage.actual_completion_tokens,
                    None if usage is None else usage.actual_total_tokens,
                    None if usage is None else usage.actual_reasoning_tokens,
                    None if usage is None else usage.actual_cached_tokens,
                    reason,
                    now_dt.isoformat(),
                    attempt_id,
                    owner_token,
                ),
            )
            if cur.rowcount != 1:
                raise CacheStateError("Failed to block solver run")

    def fence_expired_claim(
        self,
        attempt_id: str,
        *,
        reason: str = "lease_expired_fenced",
        now: datetime | None = None,
    ) -> str:
        """Fence an expired claim. Never auto-replays; transitions to blocked_uncertain."""
        _require_nonempty_str(attempt_id, "attempt_id")
        _require_nonempty_str(reason, "reason", max_len=MAX_REASON_CHARS)
        now_dt = parse_utc_timestamp(_now_iso(now))
        with self._transaction() as db:
            row = db.execute(
                "SELECT * FROM solver_runs WHERE attempt_id = ?", (attempt_id,)
            ).fetchone()
            if row is None:
                raise CacheOwnershipError("Unknown solver attempt_id")
            self._verify_solver_row_integrity(row)
            if row["execution_state"] not in {"claimed", "dispatched"}:
                raise CacheStateError("Run is not in an active claimed/dispatched state")
            lease_exp = parse_utc_timestamp(row["lease_expires_at"])
            if now_dt < lease_exp:
                raise CacheStateError("Cannot fence an active lease before lease_expires_at")
            # Rotate owner_token to fence the stale worker and block automatic rerun
            fenced_token = "fenced-" + uuid4().hex
            db.execute(
                "UPDATE solver_runs SET "
                "  owner_token = ?, "
                "  execution_state = 'blocked_uncertain', "
                "  candidate_outcome = 'undetermined', "
                "  evidence_validity = 'infrastructure_error', "
                "  failure_reason = ?, "
                "  updated_at = ? "
                "WHERE attempt_id = ? AND execution_state IN ('claimed', 'dispatched')",
                (fenced_token, reason, now_dt.isoformat(), attempt_id),
            )
            return "blocked_uncertain"

    def mark_reservation_finalized(
        self,
        attempt_id: str,
        owner_token: str,
        *,
        ledger_state: str,
        now: datetime | None = None,
    ) -> None:
        """Record that CreditLedger.finish_run has completed for this run's reservation."""
        if ledger_state not in {"completed", "uncertain"}:
            raise CacheValidationError("ledger_state must be 'completed' or 'uncertain'")
        now_dt = parse_utc_timestamp(_now_iso(now))
        target_res_state = (
            "finalized_completed" if ledger_state == "completed" else "finalized_uncertain"
        )
        with self._transaction() as db:
            row = self._require_owned_solver_run(
                db, attempt_id, owner_token, now_dt, check_lease=False
            )
            if row["namespace"] != "live" or row["reservation_state"] != "reserved":
                raise CacheStateError("Run does not have an active 'reserved' reservation")
            if ledger_state == "completed" and row["execution_state"] != "completed":
                raise CacheStateError(
                    "Cannot mark reservation finalized_completed on an incomplete solver run"
                )
            cur = db.execute(
                "UPDATE solver_runs SET reservation_state = ?, updated_at = ? "
                "WHERE attempt_id = ? AND owner_token = ? AND reservation_state = 'reserved'",
                (target_res_state, now_dt.isoformat(), attempt_id, owner_token),
            )
            if cur.rowcount != 1:
                raise CacheStateError("Failed to finalize reservation state")

    def revalue_solver_run(
        self,
        attempt_id: str,
        *,
        pricing_version: str,
        input_usd_per_million: str,
        output_usd_per_million: str,
        now: datetime | None = None,
    ) -> CostValuation:
        """Append a new price valuation without altering solver_key or original recorded cost."""
        _require_nonempty_str(attempt_id, "attempt_id")
        now_iso = _now_iso(now)
        with self._transaction() as db:
            row = db.execute(
                "SELECT * FROM solver_runs WHERE attempt_id = ?", (attempt_id,)
            ).fetchone()
            if row is None:
                raise CacheValidationError("Unknown solver attempt_id")
            self._verify_solver_row_integrity(row)
            if (
                row["execution_state"] != "completed"
                or row["accounting_mode"] != "provider"
                or row["actual_prompt_tokens"] is None
                or row["actual_completion_tokens"] is None
            ):
                raise CacheStateError(
                    "Price revaluation requires a completed run with actual provider token counts"
                )
            valuation = CostValuation.from_token_usage(
                pricing_version=pricing_version,
                input_usd_per_million=input_usd_per_million,
                output_usd_per_million=output_usd_per_million,
                prompt_tokens=row["actual_prompt_tokens"],
                completion_tokens=row["actual_completion_tokens"],
                explicit_zero_cost=bool(row["explicit_zero_usage"]),
            )
            db.execute(
                "INSERT INTO cost_valuations ("
                "  valuation_id, attempt_id, is_original, pricing_version, "
                "  input_price_usd_per_m, output_price_usd_per_m, cost_nanos, "
                "  explicit_zero_cost, recorded_at"
                ") VALUES (?, ?, 0, ?, ?, ?, ?, ?, ?)",
                (
                    uuid4().hex,
                    attempt_id,
                    valuation.pricing_version,
                    valuation.input_usd_per_million,
                    valuation.output_usd_per_million,
                    valuation.cost_nanos,
                    int(valuation.explicit_zero_cost),
                    now_iso,
                ),
            )
            return valuation

    def record_score(
        self,
        scoring_identity: ScoringIdentity,
        *,
        solver_attempt_id: str,
        score_artifact: ScoreArtifact,
        now: datetime | None = None,
    ) -> str:
        """Record an evaluator result bound to solver_key and exact candidate patch SHA-256."""
        if type(scoring_identity) is not ScoringIdentity:
            raise CacheValidationError("Expected a ScoringIdentity instance")
        if type(score_artifact) is not ScoreArtifact:
            raise CacheValidationError("Expected a ScoreArtifact instance")
        _require_nonempty_str(solver_attempt_id, "solver_attempt_id")
        now_iso = _now_iso(now)
        s_key = scoring_identity.scoring_key()
        s_json = canonical_json_bytes(scoring_identity.to_canonical_dict()).decode("ascii")

        with self._transaction() as db:
            solver_row = db.execute(
                "SELECT * FROM solver_runs WHERE attempt_id = ?", (solver_attempt_id,)
            ).fetchone()
            if solver_row is None:
                raise CacheValidationError("Unknown solver_attempt_id")
            self._verify_solver_row_integrity(solver_row)
            if solver_row["execution_state"] != "completed":
                raise CacheStateError("Cannot score an incomplete solver run")
            if solver_row["solver_key"] != scoring_identity.solver_key:
                raise CacheValidationError(
                    "ScoringIdentity.solver_key does not match solver run's solver_key"
                )
            if solver_row["patch_sha256"] != scoring_identity.candidate_patch_sha256:
                raise CacheValidationError(
                    "ScoringIdentity.candidate_patch_sha256 does not match stored patch_sha256"
                )
            namespace = solver_row["namespace"]
            if namespace == "synthetic" and scoring_identity.registration_id is not None:
                raise CacheValidationError(
                    "Synthetic namespace runs cannot be bound to a Stage B registration_id"
                )

            existing_sid = db.execute(
                "SELECT * FROM score_identities WHERE scoring_key = ?", (s_key,)
            ).fetchone()
            if existing_sid is None:
                db.execute(
                    "INSERT INTO score_identities ("
                    "  scoring_key, solver_key, candidate_patch_sha256, "
                    "  registration_id, identity_json, created_at"
                    ") VALUES (?, ?, ?, ?, ?, ?)",
                    (
                        s_key,
                        scoring_identity.solver_key,
                        scoring_identity.candidate_patch_sha256,
                        scoring_identity.registration_id,
                        s_json,
                        now_iso,
                    ),
                )
            else:
                parsed_sid = ScoringIdentity.from_canonical_json(existing_sid["identity_json"])
                if parsed_sid.scoring_key() != s_key or existing_sid["identity_json"] != s_json:
                    raise CacheCorruptionError("Stored score_identity collision or corruption")

            existing_score = db.execute(
                "SELECT * FROM score_runs "
                "WHERE namespace = ? AND scoring_key = ? "
                "AND execution_state IN ('claimed', 'completed', 'blocked_uncertain')",
                (namespace, s_key),
            ).fetchone()
            if existing_score is not None:
                raise CacheStateError(
                    "A completed or blocked score already exists for this scoring_key"
                )

            score_attempt_id = uuid4().hex
            exec_state = (
                "completed"
                if score_artifact.evidence_validity == "valid"
                else "blocked_uncertain"
            )
            db.execute(
                "INSERT INTO score_runs ("
                "  score_attempt_id, scoring_key, solver_attempt_id, namespace, "
                "  registration_id, owner_token, claimed_at, lease_expires_at, updated_at, "
                "  execution_state, scorer_status, candidate_outcome, evidence_validity, "
                "  reason, phase, baseline_verified, prepared_archive_sha256, "
                "  private_envelope_sha256"
                ") VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
                (
                    score_attempt_id,
                    s_key,
                    solver_attempt_id,
                    namespace,
                    scoring_identity.registration_id,
                    uuid4().hex,
                    now_iso,
                    now_iso,
                    now_iso,
                    exec_state,
                    score_artifact.scorer_status,
                    score_artifact.candidate_outcome,
                    score_artifact.evidence_validity,
                    score_artifact.reason,
                    score_artifact.phase,
                    int(score_artifact.baseline_verified),
                    score_artifact.prepared_archive_sha256,
                    score_artifact.private_envelope_sha256,
                ),
            )
            db.execute(
                "UPDATE solver_runs SET "
                "  candidate_outcome = ?, "
                "  evidence_validity = ?, "
                "  updated_at = ? "
                "WHERE attempt_id = ?",
                (
                    score_artifact.candidate_outcome,
                    score_artifact.evidence_validity,
                    now_iso,
                    solver_attempt_id,
                ),
            )
            return score_attempt_id

    def get_solver_run(self, attempt_id: str) -> dict[str, Any]:
        """Read full private solver run record including patch bytes and cost valuations."""
        _require_nonempty_str(attempt_id, "attempt_id")
        with self._transaction() as db:
            row = db.execute(
                "SELECT * FROM solver_runs WHERE attempt_id = ?", (attempt_id,)
            ).fetchone()
            if row is None:
                raise CacheValidationError("Unknown solver attempt_id")
            self._verify_solver_row_integrity(row)
            valuations = db.execute(
                "SELECT * FROM cost_valuations WHERE attempt_id = ? ORDER BY rowid ASC",
                (attempt_id,),
            ).fetchall()
            scores = db.execute(
                "SELECT * FROM score_runs WHERE solver_attempt_id = ? ORDER BY rowid ASC",
                (attempt_id,),
            ).fetchall()
            result = dict(row)
            result["valuations"] = [dict(v) for v in valuations]
            result["scores"] = [dict(s) for s in scores]
            return result

    def list_attempts_for_key(self, namespace: str, solver_key: str) -> list[dict[str, Any]]:
        """Return all historical attempts (including failed/aborted) for a solver_key."""
        if namespace not in VALID_NAMESPACES:
            raise CacheValidationError("Invalid namespace")
        _require_hex64(solver_key, "solver_key")
        with self._transaction() as db:
            rows = db.execute(
                "SELECT * FROM solver_runs "
                "WHERE namespace = ? AND solver_key = ? ORDER BY rowid ASC",
                (namespace, solver_key),
            ).fetchall()
            for r in rows:
                self._verify_solver_row_integrity(r)
            return [dict(r) for r in rows]

    def export_summary(
        self,
        attempt_id: str,

def test_concurrent_claims_have_single_owner_without_sleeps(cache: RunCache):
    solver_id = SolverIdentity.from_dict(synthetic_metadata())
    barrier = threading.Barrier(2)

    def worker(_: int):
        local_store = RunCache(cache.path)
        barrier.wait(timeout=5)
        try:
            return local_store.claim_solver_run(solver_id, now=NOW)
        except CacheBusyError:
            return None

    with ThreadPoolExecutor(max_workers=2) as pool:
        outcomes = list(pool.map(worker, range(2)))

    acquired = [o for o in outcomes if o is not None and o.acquired]
    losers = [o for o in outcomes if o is None or not o.acquired]
    assert len(acquired) == 1
    assert len(losers) == 1
    winner = acquired[0]
    assert winner.owner_token is not None
    if losers[0] is not None:
        assert losers[0].owner_token is None
        assert losers[0].status == "already_claimed"
        assert losers[0].attempt_id == winner.attempt_id

    assert new_state == "blocked_uncertain"

    # 4. Subsequent claims see blocked_uncertain and never auto-rerun
    after_fence = cache.claim_solver_run(solver_id, now=expired_time)
    assert not after_fence.acquired
    assert after_fence.status == "blocked_uncertain"

# Case 5: Crash injection across all handshake stages + reopen verification

@pytest.mark.parametrize(
    "stage",
    [
        "after_claim_pre_dispatch_abort",
        "after_reservation_intent_before_ledger",
        "after_ledger_reserve_before_bind",
        "after_dispatch_before_response",
        "after_complete_before_ledger_finish",
    ],
)
def test_crash_injection_stages_and_reopen_state(tmp_path: Path, stage: str):
    cache_path = tmp_path / f"cache_{stage}.sqlite3"
    ledger_path = tmp_path / f"ledger_{stage}.sqlite3"

    store = RunCache(cache_path)
    store.initialize(now=NOW)
    ledger = CreditLedger(ledger_path)
    ledger.initialize(
        balance_usd="29.50",
        reserve_usd="3",
        allowance_usd="0.10",
        expires_at=NOW + timedelta(days=60),
        exclusive_use=True,
        now=NOW,
    )

    solver_id = SolverIdentity.from_dict({**synthetic_metadata(), "namespace": "live"})
    claim = store.claim_solver_run(
        solver_id, now=NOW, ledger_status=ledger.status(now=NOW)
    )
    assert claim.acquired and claim.owner_token is not None

    if stage == "after_claim_pre_dispatch_abort":
        # Clean pre-dispatch abort before any reservation intent: eligible for replay!
        store.abort_before_dispatch(
            claim.attempt_id, claim.owner_token, reason="cancelled_pre_reserve", now=NOW
        )
        reopened = RunCache(cache_path)
        reclaim = reopened.claim_solver_run(
            solver_id, now=NOW, ledger_status=ledger.status(now=NOW)
        )
        assert reclaim.acquired and reclaim.attempt_id != claim.attempt_id
        # Historical aborted attempt is retained
        history = reopened.list_attempts_for_key("live", solver_id.solver_key())
        assert len(history) == 2
        assert history[0]["execution_state"] == "aborted_pre_dispatch"
        assert history[1]["execution_state"] == "claimed"
        return

    store.begin_reservation_intent(
        claim.attempt_id, claim.owner_token, planned_usd="0.02", now=NOW
    )
    if stage == "after_reservation_intent_before_ledger":
        # Crash before ledger.reserve_run: reopened cache blocks new live claims
        reopened = RunCache(cache_path)
        with pytest.raises(CacheBlockedError):
            reopened.check_live_handshake_ready(ledger.status(now=NOW))
        return

    res_id = ledger.reserve_run("0.02", now=NOW)
    if stage == "after_ledger_reserve_before_bind":
        # Crash after ledger.reserve_run committed, before cache.bind_reservation!
        reopened_cache = RunCache(cache_path)
        reopened_ledger = CreditLedger(ledger_path)
        assert Decimal(reopened_ledger.status(now=NOW)["reserved_usd"]) == Decimal("0.02")
        with pytest.raises(CreditError, match="unfinished"):
            reopened_ledger.reserve_run("0.01", now=NOW)
        with pytest.raises(CacheBlockedError):
            reopened_cache.check_live_handshake_ready(reopened_ledger.status(now=NOW))
        return

    store.bind_reservation(
        claim.attempt_id, claim.owner_token, reservation_id=res_id, now=NOW
    )
    store.mark_dispatched(claim.attempt_id, claim.owner_token, now=NOW)
    if stage == "after_dispatch_before_response":
        # Crash while request is in flight: no silent refund, no replay even after lease expiry
        reopened_cache = RunCache(cache_path)
        reopened_ledger = CreditLedger(ledger_path)
        later = NOW + timedelta(minutes=10)
        dup = reopened_cache.claim_solver_run(solver_id, now=later)
        assert not dup.acquired and dup.status == "already_claimed"
        assert Decimal(reopened_ledger.status(now=NOW)["reserved_usd"]) == Decimal("0.02")
        return

    if stage == "after_complete_before_ledger_finish":
        val = CostValuation.from_token_usage(
            pricing_version="v1",
            input_usd_per_million="0.06",
            output_usd_per_million="0.24",
            prompt_tokens=400,
            completion_tokens=50,
        )
        store.complete_solver_run(
            claim.attempt_id,
            claim.owner_token,
            artifact=make_solver_artifact(),
            usage=make_provider_usage(400, 50),
            valuation=val,
            now=NOW,
        )
        reopened_cache = RunCache(cache_path)
        reopened_ledger = CreditLedger(ledger_path)
        # Artifact is reusable offline, but live handshake is blocked until ledger finishes
        reuse = reopened_cache.claim_solver_run(solver_id, now=NOW)
        assert not reuse.acquired and reuse.status == "reused_completed"
        with pytest.raises(CacheBlockedError):
            reopened_cache.check_live_handshake_ready(reopened_ledger.status(now=NOW))

# Case 6: Transaction rollback, busy DB, missing DB, and corrupt rows
# ---------------------------------------------------------------------------


def test_non_sql_exception_rolls_back_and_corrupt_or_missing_db_fails_safely(
    tmp_path: Path,
):
    missing_path = tmp_path / "does_not_exist.sqlite3"
    missing_cache = RunCache(missing_path)
    solver_id = SolverIdentity.from_dict(synthetic_metadata())

    # Read/claim on missing DB must raise CacheMissingError without creating a file
    with pytest.raises(CacheMissingError):
        missing_cache.claim_solver_run(solver_id, now=NOW)
    assert not missing_path.exists()

    # Initialize cannot overwrite an existing file
    db_path = tmp_path / "valid.sqlite3"
    cache = RunCache(db_path)
    cache.initialize(now=NOW)
    original_bytes = db_path.read_bytes()
    with pytest.raises(FileExistsError):
        cache.initialize(now=NOW)
    assert db_path.read_bytes() == original_bytes

    # Non-SQL exception inside _transaction rolls back partial writes
    claim = cache.claim_solver_run(solver_id, now=NOW)
    with pytest.raises(RuntimeError, match="injected crash"):
        with cache._transaction() as db:
            db.execute(
                "UPDATE solver_runs SET execution_state = 'completed' WHERE attempt_id = ?",
                (claim.attempt_id,),
            )
            raise RuntimeError("injected crash")
    row = cache.get_solver_run(claim.attempt_id)
    assert row["execution_state"] == "claimed"

    # Busy database fails immediately with CacheBusyError
    with sqlite3.connect(db_path) as ext_conn:
        ext_conn.execute("BEGIN IMMEDIATE")
        with pytest.raises(CacheBusyError):
            cache.get_solver_run(claim.attempt_id)

    # Corrupt patch hash in DB is caught on read/claim
    cache.complete_solver_run(
        claim.attempt_id,
        claim.owner_token,
        artifact=make_solver_artifact(),
        usage=make_synthetic_usage(),
        now=NOW,
    )
    with sqlite3.connect(db_path) as ext_conn:
        ext_conn.execute(
            "UPDATE solver_runs SET patch_sha256 = ? WHERE attempt_id = ?",
            ("0" * 64, claim.attempt_id),
        )
        ext_conn.commit()
    with pytest.raises(CacheCorruptionError):
        cache.get_solver_run(claim.attempt_id)

    # Schema version mismatch is rejected without altering the file
    with sqlite3.connect(db_path) as ext_conn:
        ext_conn.execute("UPDATE cache_meta SET schema_version = 999 WHERE id = 1")
        ext_conn.commit()
    snap = db_path.read_bytes()
    with pytest.raises(CacheSchemaError):
        cache.list_attempts_for_key("synthetic", solver_id.solver_key())
    assert db_path.read_bytes() == snap

Live Inference Remains Locked: LIVE_INFERENCE_ENABLED = False in dojo/verify.py and LockedProviderTransport in dojo/solve/contracts.py remain strictly locked pending 6a (confirmed promotional credit balance, earliest expiry, and exclusive account usage).

Prioritized Evidence-Backed Observations in Supplied Code
CreditLedger Orphan Window Across Two SQLite Files (dojo/store/credits.py:124-137): Because CreditLedger.reserve_run generates ident = uuid4().hex internally and commits immediately inside spend.sqlite3, a process crash before the caller records ident leaves a 'pending' reservation in spend.sqlite3. Our RunCache.begin_reservation_intent + check_live_handshake_ready design detects both sides of this window and fails closed without ever issuing a second reservation. If a future reviewed task (6b/6d) extends CreditLedger, adding an optional client_intent_id column to reservations would allow direct deterministic cross-DB reconciliation.
