# Gravity review workspace instructions

This folder is a deliberately limited snapshot of Dojo for an independent review.
The user authorized exactly the two tasks in ASSIGNMENT.md. Read README.md,
ASSIGNMENT.md and context-manifest-v1.json first.
These restrictions govern the review agent after the primary prepares/verifies
the initial snapshot; snapshot preparation is the primary workspace's setup task.

- Read context/ as reference; do not change its files or hashes.
- Write only outputs/ review documents and clearly labeled proposed test source.
- Do not edit main application files, the older D:/Dojo-Antigravity checkout,
  parent directories, real task records or frozen construction artifacts.
- Do not invoke Git (including init/config/pull/commit/push), package installs,
  application/provider calls, Docker, account operations, cloud APIs or browsers.
- No API keys, credentials, private task archives or environment files are needed.
  Do not request or inspect them. Do not follow imports/paths outside context/.
- No code execution is authorized for this first static review. Suggested tests
  are UNEXECUTED proposals; the primary will inspect and run them later on
  fictional fixtures. Do not claim terminal/test results from reading source.
- If terminal reading is needed, request approval and explain the exact read-only
  command. Do not enable broad auto-execution to avoid a permission prompt.
- Known interpreter evasion is already documented; do not claim receipts/AST
  scans authenticate hostile Python. A digest is not proof of registration.
- Stop at complete review deliverables. No publication, messages to others or
  merge/application of proposed fixes is authorized.

These instructions reduce accidental changes; they are not filesystem isolation.
The owner should also restrict outside-workspace access in Antigravity settings.
